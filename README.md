# RadarScan

Android-приложение для диагностики Wi-Fi и локальной сети.

## Возможности

- Радар и список обнаруженных Wi-Fi сетей: SSID, BSSID, RSSI, частота, канал, защита.
- Оценка расстояния по RSSI — ориентировочная, с большой погрешностью; направление на обычный роутер Android не сообщает.
- Информация о текущем подключении и IP шлюза.
- Проверка отклика шлюза (может не работать, если роутер блокирует ICMP).
- Сводка по загруженности каналов по числу видимых сетей, не спектральный анализ.
- История уровня сигнала во время работы приложения.
- Светлая и тёмная тема.
- Поиск устройств в локальной IPv4-подсети.
- Проверка скорости интернета: загрузка/отдача и время ответа через публичные серверы Cloudflare.
- Подсказки по слабому уровню сигнала.
- Избранные Wi-Fi сети, сохранённые локально на устройстве.
- Экспорт текстового отчёта через системное меню «Поделиться».
- Собственная адаптивная иконка RadarScan.

## Важные ограничения

Android может ограничивать Wi-Fi сканирование и возвращать кэшированные результаты. Для поиска локальных устройств используется проверка доступности IP-адресов; устройства, блокирующие такие запросы, могут не обнаружиться. Поиск выполняется только в типичной IPv4-подсети /24, определяемой текущим Wi-Fi IP телефона. Это не полноценный инвентаризатор сети и не определение типа устройства.

Тест скорости зависит от сервера, тарифа, сигнала и трафика. Результаты являются ориентировочными. Для теста требуется интернет-соединение; загружаются/отправляются тестовые данные.

Оценка расстояния по RSSI не является измерением дальномером. Сведения о производителе роутера могут быть недоступны из-за ограничений Android и рандомизации MAC-адресов.

## Сборка

- JDK 17.
- minSdk 24, targetSdk 34.
- Команда: `gradle :app:assembleDebug`.
- APK: `app/build/outputs/apk/debug/app-debug.apk`.

## GitHub Actions

Workflow **Android APK** запускается при push, pull request и вручную через Actions. APK публикуется в Artifacts.

## Разрешения

Для Wi-Fi сканирования Android может запросить местоположение или доступ к устройствам поблизости. Для локального поиска и теста интернета требуется сетевой доступ. Разрешения и доступность функций зависят от версии Android и настроек устройства.
