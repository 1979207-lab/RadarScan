# RadarScan

Android-приложение для визуального анализа доступных Wi-Fi сетей.

## Возможности

- Сканирование видимых Wi-Fi точек через Android `WifiManager`.
- Отображение SSID, BSSID, RSSI, частоты, канала и параметров защиты.
- Радарная визуализация с цветовой индикацией уровня сигнала. Угол точки условный, Android не предоставляет направление на обычную точку доступа.
- Оценка расстояния по RSSI с широким ориентировочным диапазоном. Это не измерение дальномером: стены, мощность передатчика, антенны и помехи сильно влияют на оценку.
- Информация о текущем подключении: SSID, BSSID, IP шлюза, уровень сигнала и частота.
- Проверка доступности шлюза (результат зависит от того, отвечает ли роутер на ICMP).
- Сводка по каналам на основе количества обнаруженных сетей. Это не спектральный анализ радиоэфира.
- История уровня сигнала текущего подключения во время работы приложения.
- Переключение светлой и тёмной темы с сохранением выбора.

## Сборка

- JDK 17.
- minSdk 24, targetSdk 34.
- Команда: `gradle :app:assembleDebug`.
- APK: `app/build/outputs/apk/debug/app-debug.apk`.

## GitHub Actions

Workflow **Android APK** запускается при push в main/master, при pull request и вручную через Actions. APK публикуется в Artifacts.

## Разрешения и ограничения

Для сканирования Wi-Fi требуется разрешить доступ к местоположению/устройствам поблизости и включить системную геолокацию, если этого требует версия Android. Android ограничивает частоту Wi-Fi-сканирования; результаты могут быть кэшированными. Приложение не может обойти эти системные ограничения обычным публичным API.

Сканирование выполняется через `WifiManager.startScan()`, который устарел в новых Android API и может быть ограничен системой. Для точного измерения расстояния или направления до обычного роутера нужны дополнительные аппаратные возможности или инфраструктура позиционирования.
